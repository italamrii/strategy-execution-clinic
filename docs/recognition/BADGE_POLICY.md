# Badge Policy

- Issuance modes: automatic, manual, hybrid
- Prestigious badges (Volunteer Leader, AI Pioneer, etc.) require human approval
- Automatic issuance is idempotent (one active award per definition/user)
- Public verification via non-sequential `SEC-BDG-…` codes
- Revocation preserves history and updates public verification immediately
If approved hours later drop below a milestone threshold, the milestone row remains. Current totals are authoritative separately.
