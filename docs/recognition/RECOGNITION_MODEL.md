# Recognition Model (Phase 5)

الإنجاز المهني يجب أن يكون قابلاً للإثبات، وليس مجرد شارة.

Clinic recognition is issued only from authoritative records:

membership · volunteering · approved contributions

Displayed achievements are never self-declared totals.

## Layers

1. Contribution submissions and review (no self-approval)
2. Impact events + recalculable score (weights in `impact_rules`)
3. Badges (automatic / manual / hybrid) — **badge ≠ RBAC role**
4. Certificates tied to a source record; PDF is a snapshot, verification page is live truth
5. Public professional profile + opted-in directory
6. Social share kit (`SOCIAL_CARD_V1`) 1080×1080, 1080×1350, 1200×628

Public identifiers: membership credential codes, `SEC-BDG-*`, `SEC-CRT-*`. Handles are optional and reserved-word protected.

Not claimed: Open Badges 3.0, government accreditation, professional licensing, LinkedIn certification APIs.
