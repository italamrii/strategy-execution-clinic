# Public Profile Privacy

Members control visibility flags in `public_profile_settings`.

Never exposed publicly:

- email, phone, legal name
- internal user IDs
- rejected contributions
- private evidence
- admin / review notes
- security events

Credential status remains authoritative: privacy settings cannot make REVOKED/SUSPENDED/EXPIRED appear ACTIVE.

## Public handle changes (future)

Handle change history and redirects are **not** implemented in Phase 5. Changing a public handle does not preserve prior vanity URLs.

Credential public codes (`SEC-…`) remain the stable verification identifier for membership, badges, and certificates.
